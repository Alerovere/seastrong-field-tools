# Underwater Photogrammetry

Field setup and procedures for collecting Structure-from-Motion (SfM) photogrammetric surveys on coral reefs and seagrass beds using a two-camera GoPro rig.

## Contents

| File | Description |
|------|-------------|
| *(no processing scripts)* | This tool has no automated processing pipeline — see Processing below |

## Processing

Photos collected with this rig are processed in two external software packages:

1. **DaVinci Resolve** — colour correction using the colour reference tab photographed at the start of each transect
2. **Agisoft Metashape** — SfM reconstruction, scale bar definition from photogrammetric targets, 3D model and orthomosaic export

## Full documentation

See the [full documentation](https://seastrong-field-tools.readthedocs.io/en/latest/underwater_photogrammetry.html) for the complete field setup, camera settings, baseline rig configuration table, and step-by-step field procedure.

## SEASTRONG context

This tool supports **Task 1.3** (baseline characterisation of biodiversity and ecosystem condition within corridors), **Task 2.2** (experimental restoration site setup), and **Task 5.1** (monitoring restoration-driven structural complexity gains) of the SEASTRONG project (HORIZON-CL6-2025-01-BIODIV-07).
